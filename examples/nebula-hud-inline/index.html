<nebula-hud> -- inline expand/collapse example

This page demonstrates the inline expand mode of the <nebula-hud> Web Component adapter (src/runtime/adapters/nebula-hud.ts, IncusLuminis/assets#46). It requires zero JavaScript beyond the one <script type="module"> import below -- the element registers and mounts itself.

The element below starts collapsed (variant="mini"). Click its top-left toggle button: it calls hud.setVariant("maxi") on the exact same Hud instance, mounted into the exact same container. There is no fixed height on the container, so it grows to fit whatever composition is now mounted -- watch the "AFTER THE HUD" marker below get pushed down the page as it expands, and pulled back up when you collapse it again. This is real document reflow, not an overlay.

↓ AFTER THE HUD ↓ -- watch this get pushed down when you expand the panel above, and pulled back up when you collapse it.

Some more page content, so there is real room below the element for the page to reflow into. In a spatially fixed layout with no reflow room (e.g. a HUD sitting among other fixed instruments), inline mode is the wrong choice -- that case is modal mode, a separate, not-yet-built follow-up (see src/runtime/adapters/README.md).
