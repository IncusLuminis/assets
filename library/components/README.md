# library/components/

Reserved for the **Component Registry** — reusable authoring primitives
(frames, corners, brackets, grids, reticles, indicators, labels, typography,
scanlines, noise, screen fragments, decorative geometry, animation
fragments) consumed primarily by Visual Composer (Architecture §8.2). Not
required to be independently runtime-mountable.

Deliberately empty in Story #5 and for the remainder of Platform 0.1
(Architecture §51: Component Registry is Platform **0.2** scope). Explicitly
out of this Story's scope ("component-library contents").
